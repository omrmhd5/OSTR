# OSTR - Ecommerce Fashion Website 🛍️

An interactive ecommerce fashion platform built with the MERN stack, delivering a smooth, secure, and responsive shopping experience for 200+ products. OSTR supports user and admin roles, with a robust JWT-based authentication system, complete product management, and a modern, elegant interface.

## Features ✅

* **MERN Stack Architecture** – MongoDB, Express.js, React.js, Node.js
* **JWT Authentication** – Secure login and role-based access
* **Admin Dashboard** – Manage products, categories, orders, and users
* **Custom Clothing Design** – Personalize and preview custom outfits
* **Dynamic Catalog** – Men's, women's, and kids' sections with filters
* **Wishlist & Cart** – Seamlessly save and manage purchases
* **Secure Checkout** – Integrated payment with real-time updates
* **Responsive Dark Mode** – Consistent, elegant look on all devices
* **Real-Time Database** – Instant updates for orders and product changes

## How It Works ⚙️

1. Users sign up or log in with secure JWT.
2. Browse products by category or search.
3. Customize, add to cart, or add to wishlist.
4. Place orders with real-time status tracking.
5. Admins manage all products, users, and orders via a secure dashboard.

## Technologies Used 🛠️

* **Frontend:** React.js, TailwindCSS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Authentication:** JSON Web Tokens (JWT)
* **Hosting:** Deployed on GitHub Pages / Vercel / Render (specify if you want)
